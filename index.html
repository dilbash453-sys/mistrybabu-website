7. मौजूदा Master File के साथ Integration Rule

सबसे जरूरी नियम: 25 features को 25 नए नीचे वाले boxes/pages बनाकर नहीं जोड़ा जाएगा।

Quote, Deal, Agreement, Rating और Complaint एक ही Job/Deal flow में रहेंगे।
Verified, Portfolio और Membership Profile के अंदर रहेंगे।
Material, Shopkeeper और Delivery एक ही Material Marketplace में रहेंगे।
Paid Leads, Advertisement और सभी Income Sources Admin Business Dashboard में रहेंगे।

✓ Existing Customer/Mistri/Contractor/Aadhaar/Admin systems को आधार माना जाएगा।

अगला implementation चरण: existing 4,421-line Master में exact page/function mapping → फिर feature-by-feature integration → फिर click-flow testing.
